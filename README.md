# Mathematical modeling of BMP4 differentaiton therapy

This repository contains all the code to perform model simulations and results presented in: Mathematical modeling of cancer stem cells and BMP4 differentiation therapy.

Each notebook contains various results. The main code to simulate the model is in `gsc_model_functions.py`.

The python packages you need to run these notebooks are listed at the top of each notebook.
The only packages you should need to run this code are: numpy, matplotlib, scipy
